**Add, remove and reorder items.** Arrange the expanded panel and the collapsed bar your way, for example show only tasks when expanded, without quota. Click an item to see its settings; the round button at its end adds or removes it.

**A better collapsed bar.** Adjust its size, keep its place on each screen, and get more from each item.

**A fresh look.** New materials and finer animations.

**Codex Dot tasks.** Restart Codex the first time. Dot tasks run in the cloud, so Pacer shows their progress but not yet their speed. On Windows, this needs Codex from the Microsoft Store.

**Fixes.** The Codex progress ring also moves with third-party APIs. Finished Claude tasks no longer stay on **Working on a task**, and Pacer works alongside your own Claude Code telemetry settings. Fixed a crash on Windows 10; if the engine stops unexpectedly, it leaves a crash report you can attach to an issue.
