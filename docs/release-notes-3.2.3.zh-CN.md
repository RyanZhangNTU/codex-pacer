Codex Pacer 3.2.3 将展开态的两个额度窗口合并到同一个圆环中。

- **两种样式自由切换：** 默认使用分段圆环；在“设置 → 外观 → 展开态额度”中选择“经典”即可切回原版，立即生效并记住选择。
- **上方 5h，下方 7d：** 较短的上弧显示 5 小时额度，较长的下弧显示 7 天额度，各自保留剩余百分比、重置倒计时和白色配速刻度。只开启一个服务或同时开启两个服务都使用同样的布局。
- 5 小时额度不足或使用偏快时，上弧和数值变为琥珀色。数据缺失或过期时，每个周期分别显示自己的状态。
- 没有 5 小时限制时，保留完整的每周圆环；只开启 Codex 时保留原有额度条。

### 安装

- **已有安装：** 通过“检查更新”原地升级，保留现有设置。
- **手动安装：** 先退出 Codex Pacer，再用新版替换“应用程序”中的副本，然后重新打开。
- 需要 macOS 14 及以上。
