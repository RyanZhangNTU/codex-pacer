**Codex 重置券。**历史页显示还有几张重置券、每一张还剩多久；展开面板的 Codex 额度下方也有一个胶囊，最近一张的过期时间一眼可见。快过期时 Pacer 会提醒你，提前几天可以在 **设置 → 通知** 里设置（[#238](https://github.com/RyanZhangNTU/codex-pacer/issues/238)）。

**回到顶部居中。**常拖动灵动岛的话，可以在展开面板的标题栏加一个按钮，一键放回顶部居中。在 **展开面板 → 按钮** 里打开。

**Claude 请求使用应用时提醒。**Claude Desktop 请求使用电脑上的应用时，Pacer 会提示任务在等你，而不是显示仍在运行。

**修复。**在 Codex 对话里编辑之前的消息后，任务和进度圆环会继续显示，Windows 上任务也不会再消失（[#259](https://github.com/RyanZhangNTU/codex-pacer/issues/259)）。很长的 Codex 任务，进度圆环会一直走到结束。任务等待后台工作时，折叠栏的状态也会显示出来。Windows 上折叠栏的状态文字重新居中（[#258](https://github.com/RyanZhangNTU/codex-pacer/issues/258)），日期和时间按你的时区显示，不再是 GMT（[#264](https://github.com/RyanZhangNTU/codex-pacer/issues/264)）。

更多信息见[使用说明](https://github.com/RyanZhangNTU/codex-pacer/blob/main/docs/guide.zh-CN.md)和[完整更新记录](https://github.com/RyanZhangNTU/codex-pacer/blob/main/CHANGELOG.md)。
