# Windows 无障碍与动效行为

岛提供可用 UIA 或键盘操作的收起栏主按钮。按钮名称随固定状态变化；Space 执行主动作，Alt+左右键分页，Esc 收起。分页同时处理 WPF 的 `Key.System` / `SystemKey`，文本输入保留自己的方向键行为。设置页保留原有键盘排序和关闭动作。

淡出的任务页立即退出可访问树，并禁用命中、焦点和旧 peer 的动作。切换设置页也会禁用离开的内容。隐藏岛时关闭并禁用菜单、清除退出页和有限动画；显示后恢复当前内容。关闭窗口先停止展示，再释放视觉源，避免徽章合成层在断开后读取屏幕坐标。

## 系统设置

`SystemAppearanceSource` 通过系统事件读取浅深色、客户端动画、高对比度和透明效果，并在窗口 dispatcher 上发布不可变快照。重复事件会合并；窗口关闭后解除订阅，排队的回调不再发布。岛与设置窗口共享来源，不轮询，也不保存这些系统值。

设置跟随浅深色；岛继续使用现有深色表面。关闭系统透明效果或开启高对比度时禁用 Glass，保留用户材质偏好，系统恢复后重建材质。高对比度使用系统的窗口、文本、控件、选中和禁用语义色，保留岛轮廓外的透明区域。选中项和下拉弹窗使用选中文本色，离开高对比度后恢复资源与原有绑定。

减少动画会立即停止当前窗口、翻页、悬停、组件变暗、额度轮播和徽章动画。反向或重复输入保留最后的目标，页面在关闭动画时立即到达最终状态；不保留已完成的根时钟。遮挡期间继续沿用事件驱动的暂停与恢复规则。

徽章曲线与 Mac 存在已知差异（线性 vs Cubic/Spring），按用户决定保留。

## 验证范围

`accessibility` 展示组使用离线合成数据，在中英文下检查实际 HWND 的 UIA 名称、角色与动作，验证 Space、Alt+左右键、焦点前后移动、组件排序和 Esc。旧页 peer 必须拒绝动作；隐藏窗口没有可访问子项。弹窗验证名称、角色和语义色，选择动作从 ComboBox 的数据 peer 验证，符合 [WPF 数据与包装 peer 的分工](https://github.com/dotnet/wpf/blob/main/src/Microsoft.DotNet.Wpf/src/PresentationFramework/System/Windows/Automation/Peers/ListBoxItemWrapperAutomationPeer.cs)。

系统设置变化使用注入的快照，测试期间不修改本机系统设置。测试覆盖连续主题/高对比度变化、绑定保留、焦点保留、材质回退与恢复、进行中关闭动画、正常动画下隐藏/关闭，以及订阅和原生表面的释放。

紧凑数值按完整文本缩放，不添加省略号。测试以 100%、125%、150%、200% 的字体测量参数验证完整数值宽度，并检查 UIA 保留全部读数。测量参数不代表多屏实机验证。

引导窗口也借用同一设置源，离开步骤时禁用旧内容和按钮，关闭后解除订阅。

`Pacer.PresentationTests --unit-only` 不创建 Application 或窗口，覆盖系统键解析、快照订阅所有权、语义色绑定恢复、页面退役和有限时钟释放。

自动化覆盖实现行为，不代替 Narrator 的实际朗读体验，也不覆盖真实系统设置广播、其他显示器与缩放、不同高对比度配色和真实输入法下的焦点行为。
