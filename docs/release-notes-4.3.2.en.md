Fixed the Windows engine stopping after Pacer had been running for about 15 hours, which stopped task updates until Pacer was reopened. If the engine stops unexpectedly after running for at least 10 minutes, Pacer now restarts itself. We recommend that Windows users update promptly.

Claude cloud Projects no longer bring back a question you already answered as a new alert, show **Turn finished · Reply if needed** when you can continue a finished turn, and check again sooner when a session starts or stops.

See the [user guide](https://github.com/RyanZhangNTU/codex-pacer/blob/main/docs/guide.md) and the [full changelog](https://github.com/RyanZhangNTU/codex-pacer/blob/main/CHANGELOG.md).
