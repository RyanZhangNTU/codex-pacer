Codex Pacer 4.3.0 brings a new main window, task progress rings and new task icons to the Mac and Windows.

- New main window: Settings is now Pacer's main window, with a completely refreshed design.
- Task progress rings: follow how far each task has come, live.
- New task status icons and animations.
- Windows: much lower CPU usage.
- Other bug fixes and stability improvements.

See the [user guide](https://github.com/RyanZhangNTU/codex-pacer/blob/main/docs/guide.md) and the [full changelog](https://github.com/RyanZhangNTU/codex-pacer/blob/main/CHANGELOG.md).
