For macOS 14 or later, with support for Apple Silicon and Intel.

- Fix update dialogs appearing underneath the expanded or pinned island, leaving their buttons inaccessible.
- The island now collapses while update controls are open and resumes normal interaction when the update is dismissed, cancelled or finished.
- Background checks without a new update leave the island undisturbed.

Install from Settings → Check for Updates. If a dialog is already hidden in an older version, press Return to dismiss it, collapse the island, then check again from Settings with the pointer away from the island.

For a manual installation, quit the old app and drag Codex Pacer from the DMG into Applications. For the unsigned release, if macOS blocks the first launch, open System Settings → Privacy & Security, scroll to Security, choose Open Anyway, then reopen the installer or app.
