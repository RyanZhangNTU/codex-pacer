Codex Pacer 3.1.2 opens each task in the app that started it, including Claude and Codex tasks from third-party apps.

- Tasks started in a terminal, an editor or an app that embeds Claude or Codex, such as a Zotero plugin, show that app's name. Click one to switch straight to it.
- Sessions from those apps can be hidden in Settings → Claude and Settings → Codex. Both settings are on by default.
- Translation requests from the Zotero Agent plugin are no longer shown.
- Answered Claude questions and approvals no longer stay marked as waiting.

### Install

- **Existing installation:** use **Check for Updates** to update in place. Your preferences are preserved.
- **Manual installation:** quit Codex Pacer, replace the copy in Applications with the new app, then open it again.
- Requires macOS 14 or later.

See the [user guide](https://github.com/RyanZhangNTU/codex-pacer/blob/main/docs/guide.md) and the [full changelog](https://github.com/RyanZhangNTU/codex-pacer/blob/main/CHANGELOG.md).
