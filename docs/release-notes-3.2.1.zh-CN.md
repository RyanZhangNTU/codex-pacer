Codex Pacer 3.2.1 可以一键清除所有已结束的任务，并修复了 Claude 任务一直显示为运行中、Codex 提问可能没有提醒的问题。

- **全部标为已读：** 展开灵动岛后，点击固定按钮旁的新按钮，即可一次清除所有页面中已结束的任务。运行中以及等你回复或审批的任务不受影响，清除后重启也不会再出现。
- **设置中的更新内容：** 在“设置 → 更新内容”（位于“帮助”上方）可以随时重新查看每次更新的亮点。
- Claude Desktop 保存记录的顺序错乱时，回复结束后任务不再一直显示为运行中。
- 即使 Codex 停止向 Pacer 发送实时更新，Codex Desktop 向你提问时也会提醒你，回复后提醒自动消失。审批请求仍依赖实时更新。

### 安装

- **已有安装：** 通过“检查更新”原地升级，保留现有设置。
- **手动安装：** 先退出 Codex Pacer，再用新版替换“应用程序”中的副本，然后重新打开。
- 需要 macOS 14 及以上。

详见[使用指南](https://github.com/RyanZhangNTU/codex-pacer/blob/main/docs/guide.zh-CN.md)和[完整更新记录](https://github.com/RyanZhangNTU/codex-pacer/blob/main/CHANGELOG.md)。
