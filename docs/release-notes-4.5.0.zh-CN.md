**支持 WorkBuddy 和 WorkBuddy AI**。Pacer 像跟踪 Codex 和 Claude 一样跟踪 WorkBuddy 及其国际版 WorkBuddy AI：任务、进度圆环和账号积分，积分偏低或快到期前会提醒你。在设置里登录一次即可；开启进度圆环时，会有一个小窗口提示你每一步点哪里。

**模块库**。设置侧栏只列出这台电脑上的服务。模块库列出全部服务，其他服务可以在这里开启或获取。

**SSH 主机上的 Codex 进度**。SSH 主机（Windows 上还有 WSL）里的 Codex 任务也会显示进度圆环。已经在运行的任务，会在 Codex 重新连接后开始报告进度。

**更新连不上 GitHub 时**。检查或下载更新失败时，Pacer 会明确提示，并给出三种获取完整安装包的途径：GitHub 发布页、不需要访问 GitHub 的国内下载站 pacer.bhgmz.com，以及 QQ 群。

**修复**。睡眠唤醒或 VPN 重连后，SSH 任务会随网络恢复立即重新出现，不用再重启 Pacer。进度圆环走得更连贯；项目外开始的 Codex 对话，运行时就显示它自己的名称；贴边竖排时，额度、余额和积分的数字和上面的速度一样清楚。Windows 上的登录窗口确认账号后会自动关闭；多个文件同时变化时，任务更新也不会再漏掉；DeepSeek Harness 0.2.2 又能从面板按钮和任务行打开了；新版本的“更新内容”也能打开了。
