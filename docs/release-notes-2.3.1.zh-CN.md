适用于 macOS 14 及以上，支持 Apple Silicon 和 Intel。

- 主任务显示运行中的子代理数量，TPS 累加主代理与运行中子代理的可用速率。
- 等待新测量、调用工具或开始新轮次时保留上次测得的 TPS；15 秒内更新显示白色，之后显示灰色，折叠栏继续累加。
- 修复本轮首输出耗时中途消失及 SSH 会话缺少首输出耗时的问题。

通过“设置 → 检查更新”安装。手动安装时先退出旧应用，再将 DMG 中的 Codex Pacer 拖入 Applications。未签名发行版如被 macOS 阻止，请在“系统设置 → 隐私与安全性 → 安全性”选择“仍要打开”，再重新打开安装包或应用。
