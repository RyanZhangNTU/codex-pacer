Codex Pacer 3.0.1 is signed with Developer ID and notarized by Apple. Features are unchanged from 3.0.0.

### Install

- **From 3.0.0:** use **Check for Updates** as usual. Pacer updates in place and relaunches.
- **New install:** drag Codex Pacer from the DMG into Applications and open it. macOS asks once to confirm an app downloaded from the internet; click **Open**. You no longer need **Open Anyway** in System Settings.
- Requires macOS 14 or later, on Apple silicon or Intel.

See the [user guide](https://github.com/RyanZhangNTU/codex-pacer/blob/main/docs/guide.md) and the [full changelog](https://github.com/RyanZhangNTU/codex-pacer/blob/main/CHANGELOG.md).
