# 使用 Codex Pacer 2.1

## 安装与更新

首次安装或从未包含更新器的旧版升级时，从 GitHub Release 下载通用 DMG。手动替换前从灵动岛右下角的电源按钮或“设置 → 退出 Codex Pacer”退出旧版。安装包含更新器的版本后，可按下方“应用更新”中的方式更新。

未签名版的 DMG 可能先被系统拦截。请按 [README 中的图示步骤](../README.zh-CN.md#安装未签名版)，先双击 DMG，再到“隐私与安全”页面最下方的“安全性”放行，重新打开 DMG 后拖入“应用程序”。启动应用时若再次被拦截，按相同步骤放行 Codex Pacer。

2.0 使用正式标识 `com.codexpacer.app`。原生预览版的显示、外观、提醒、路径等设置会在首次启动时迁移，已有曲线缓存继续使用。旧 Tauri 1.x 的数据库不参与 2.0 计算。重复打开其他副本时会显示正在运行的灵动岛。

登录 Codex 后启动 Pacer。若自动发现失败，可在设置中选择 Codex CLI 与数据目录。任务监听需要 Python 3。SSH 来源沿用 Codex 中已启用的 SSH 别名、已有主机密钥和免交互认证；可在设置中关闭。

Remote Control 任务通过本机 Codex 桌面端获取状态、TPS 与首输出延迟，无需在远端安装 Pacer。请保持 Codex 开启、连接远程主机并载入对应会话；未载入或断开的会话可能没有实时数据。设置中的“统计 Codex Remote Control 任务”默认开启，可独立于 SSH 关闭。重新连接时，历史 token 仅作为计数基线，不会显示为当前速度。进度显示当前阶段与本轮结束状态，没有完成百分比。

缓存或拆分上报的计数只更新统计基线，不产生新速度；完成后的迟到用量可补充已有卡片，不重复提醒。TPS 表示观察到的响应吞吐，网络合并事件会影响读数，不等同于模型解码速度。断线本身不会被视为输入或审批请求已解决，旧提醒可能保留到重新连接后的状态更新。

CLI 自动查找覆盖 Codex 应用（包括移动后的应用位置）、PATH、Homebrew、用户安装目录，以及 nvm、fnm、Volta、asdf、mise、pnpm 等常见位置。设置会显示检测到的实际文件；可以切换其他位置，或直接选择 Codex.app、codex 文件及其所在目录。指定的手动路径失效时会明确提示，不会悄悄换用另一份 CLI。“测试连接”会检查 CLI 启动、登录状态和额度接口，不会创建任务。

## 界面语言

默认跟随 Mac 的首选语言，支持简体中文和英文；首选列表中没有这两种语言时使用英文。设置顶部的“语言”可选“跟随 macOS / 简体中文 / English”。语言变化时点击“保存并重新启动”，Pacer 会正常退出并重新打开设置，已有显示、数据来源和额度记录继续保留。Codex Pacer、Codex 等专有名词，以及任务原文和路径保持原样。

## 应用更新

首次安装包含更新器的版本后，Pacer 默认每天检查一次新版本。发现更新时会显示说明，点击安装后由应用完成下载、验证、替换和重启，保留原有设置与额度记录。更新 Pacer 不会终止 Codex 中正在运行的任务。

设置顶部的“应用更新”提供“检查更新”和自动检查开关；关闭自动检查后仍可手动更新。开关随设置页的“保存”生效。“检查更新”也可从应用菜单或启用后的菜单栏菜单打开。更新失败时，设置中会显示错误信息。

更新窗口打开时，灵动岛会自动收起，直到关闭或完成更新后恢复交互，避免遮挡更新按钮。后台检查没有发现新版本时，不会改变灵动岛的展开状态。

更新需要发布者提供有效签名的更新清单和安装包。未包含更新器的旧版仍需手动安装一次；更新源尚未发布或网络不可用时，不会把检查失败误报成已经是最新版。

## 灵动岛

悬停展开，移开收起。点击顶部或固定按钮可保持展开；Esc 收起。任务行显示当前阶段与远程来源，点击可打开会话。非默认本机数据目录的任务链接可能不可用。

少量任务时，展开面板按实际内容调整高度；超过 3 个任务后，任务区独立左右分页。使用页码两侧箭头或 Option + 左右方向键翻页，下方额度与图表保持原位，最后一页也不会改变面板高度。屏幕高度不足时，内容区仍可滚动，底部工具保持可见。

设置中的“显示模式”可选“自动 / 刘海 / 悬浮”。自动根据显示器是否有实体刘海选择布局；刘海模式贴在屏幕顶部，悬浮模式位于菜单栏下方。无实体刘海的显示器（包括非 Retina 显示器）也能手动选择刘海模式，不会留出摄像头空位。原有悬浮设置继续保留。

在“设置 → 显示 → 自定义折叠栏布局”按任务、性能、额度、警告分类选择组件。点击分类列表中的组件即可显示或隐藏，也可点布局组件上的 × 隐藏；拖动组件调整顺序或在左、右侧之间换位。灵动岛和悬浮模式都只有左、右两侧，始终一行，预览即时更新。点击一次“保存”即应用布局及当前设置，取消会丢弃本次布局编辑，“恢复默认”可还原原有布局。已有布局的中间组件会自动并入左侧。任务数量以数字徽标显示；最新 TTFT 仅显示秒数，在新测量到达前保留。额度/配速百分比及标签跟随设置中选择，剩余时间显示为当前额度窗口的百分比。警告组件仅在低额度、额度更新延迟或 SSH 未连接时出现。旧布局中的子代理数量和操作组件会移除。自适应宽度随可见组件收窄或扩展；指定宽度仍使用同一个滑块，真实刘海会预留摄像头空间。展开面板保持原有任务、额度、图表和操作布局，隐藏组件不会关闭任务监听或额度采集。

短期和七天额度显示剩余比例、重置倒计时及配速。曲线只记录当前七天周期；额度重置后开始记录接下来七天的周期。可用 banked reset 若在当前周期内到期，会在曲线对应日期显示时钟标记；悬停或点击查看到期信息。

点击“x 次重置”可展开到期详情，再次点击收起。列表按到期先后显示具体日期、时间和次数，也包括七天曲线之外的到期时间。时间使用本地时区，时区名称显示在列表下方；服务未提供的详情显示“到期时间未知”，明确不过期的重置券单独列出。到期或额度刷新后，展开的列表会同步更新。

本轮结束与中断卡片默认保留 30 分钟。可设为 5、15、30、60、240 分钟或“直到点击”。点击、状态变化或保留时间到期会移除该卡片。展开或悬停不会清除未查看的提示。

菜单栏显示默认关闭，可在设置中开启。齿轮始终可打开设置，电源按钮退出。系统通知需 macOS 授权；未授权时仍可使用灵动岛提醒。

## 数据不可用时

读取失败会显示状态与提示，不会把旧数据显示为实时结果。输出速度尚无有效样本时不显示数值；采样停顿后保留灰色估算值。重连、账户切换和新的任务轮次会更新对应状态。

额度读取失败时，展开面板会直接显示失败步骤、具体原因、可用的错误码，以及 CLI 和 Codex 数据目录；无需悬停查看。可点击“重新检测并重试”或打开设置测试连接。若仍保留上次成功读取的数据，会注明其读取时间。错误中的凭据和账户标识会被隐藏。API Key、Amazon Bedrock 等登录方式不提供 ChatGPT 订阅额度，界面会说明这一点。

部分 Codex 客户端或未来协议版本可能无法提供实时事件，Pacer 会使用日志兜底。连接成功不代表能观察所有客户端任务。“本轮结束”只表示该轮对话结束。

只有一个 SSH 来源未连接时，展开区会显示其名称；多个来源未连接时，显示“X 个 SSH 未连接”。点击该提示可打开设置，在“数据来源 → 监听 SSH 任务”下查看所有未连接的 SSH 名称与状态。Pacer 会自动重试连接。

如需反馈，请附应用版本、macOS 版本、来源类型和复现步骤；截图前隐藏私密任务标题与账户信息。
