# 使用 Codex Pacer 2.0

## 安装与更新

从 GitHub Release 下载通用 DMG。更新前从灵动岛右下角的电源按钮或“设置 → 退出 Codex Pacer”退出旧版，再替换应用。

2.0.0 为未签名版，DMG 本身可能先被系统拦截。请按 [README 中的图示步骤](../README.zh-CN.md#安装未签名版)，先双击 DMG，再到“隐私与安全”页面最下方的“安全性”放行，重新打开 DMG 后拖入“应用程序”。启动应用时若再次被拦截，按相同步骤放行 Codex Pacer。

2.0 使用正式标识 `com.codexpacer.app`。原生预览版的显示、外观、提醒、路径等设置会在首次启动时迁移，已有曲线缓存继续使用。旧 Tauri 1.x 的数据库不参与 2.0 计算。重复打开其他副本时会显示正在运行的灵动岛。

登录 Codex 后启动 Pacer。若自动发现失败，可在设置中选择 Codex CLI 与数据目录。任务监听需要 Python 3。SSH 来源沿用 Codex 中已启用的 SSH 别名、已有主机密钥和免交互认证；可在设置中关闭。

## 灵动岛

悬停展开，移开收起。点击顶部或固定按钮可保持展开；Esc 收起。任务行显示当前阶段与远程来源，点击可打开会话。非默认本机数据目录的任务链接可能不可用。

少量任务时，展开面板按实际内容调整高度；超过 3 个任务后，任务区独立左右分页。使用页码两侧箭头或 Option + 左右方向键翻页，下方额度与图表保持原位，最后一页也不会改变面板高度。屏幕高度不足时，内容区仍可滚动，底部工具保持可见。

设置中的“显示模式”可选“自动 / 刘海 / 悬浮”。自动根据显示器是否有实体刘海选择布局；刘海模式贴在屏幕顶部，悬浮模式位于菜单栏下方。无实体刘海的显示器（包括非 Retina 显示器）也能手动选择刘海模式，不会留出摄像头空位。原有悬浮设置继续保留。

短期和七天额度显示剩余比例、重置倒计时及配速。曲线只记录当前七天周期；额度重置后开始记录接下来七天的周期。可用 banked reset 若在当前周期内到期，会在曲线对应日期显示时钟标记；悬停或点击查看到期信息。

本轮结束与中断卡片默认保留 30 分钟。可设为 5、15、30、60、240 分钟或“直到点击”。点击、状态变化或保留时间到期会移除该卡片。展开或悬停不会清除未查看的提示。

菜单栏显示默认关闭，可在设置中开启。齿轮始终可打开设置，电源按钮退出。系统通知需 macOS 授权；未授权时仍可使用灵动岛提醒。

## 数据不可用时

读取失败会显示状态与提示，不会把旧数据显示为实时结果。输出速度尚无有效样本时不显示数值；采样停顿后保留灰色估算值。重连、账户切换和新的任务轮次会更新对应状态。

部分 Codex 客户端或未来协议版本可能无法提供实时事件，Pacer 会使用日志兜底。连接成功不代表能观察所有客户端任务。“本轮结束”只表示该轮对话结束。

如需反馈，请附应用版本、macOS 版本、来源类型和复现步骤；截图前隐藏私密任务标题与账户信息。
