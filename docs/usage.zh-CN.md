# 使用 Codex Pacer 3.0 候选版

3.0.0 build 48 当前用于开发与本地验收。文档介绍候选功能，不表示已经公开发布或完成全部手动测试；最新 Release 下载链接仍指向当前公开版本。

## 安装与更新

首次安装或从未包含更新器的旧版升级时，从 GitHub Release 下载通用 DMG。手动替换前从灵动岛右下角的电源按钮或“设置 → 退出 Codex Pacer”退出旧版。安装包含更新器的版本后，可按下方“应用更新”中的方式更新。

未签名版的 DMG 可能先被系统拦截。请按 [README 中的图示步骤](../README.zh-CN.md#安装未签名版)，先双击 DMG，再到“隐私与安全”页面最下方的“安全性”放行，重新打开 DMG 后拖入“应用程序”。启动应用时若再次被拦截，按相同步骤放行 Codex Pacer。

2.0 使用正式标识 `com.codexpacer.app`。原生预览版的显示、外观、提醒、路径等设置会在首次启动时迁移，已有曲线缓存继续使用。旧 Tauri 1.x 的数据库不参与 2.0 计算。重复打开其他副本时会显示正在运行的灵动岛。

安装并登录实际使用的 Codex 或 Claude Code，再启动 Pacer。设置中的“模块”默认根据已安装的应用/CLI 决定启用状态，也可独立打开或关闭 Codex、Claude，点击“保存”后生效。手动选择会在正常重启后保留；“恢复自动检测”重新交由安装检测决定。关闭一个模块只停止该模块的监听、额度请求与提醒。

Codex 自动发现失败时，可在设置中选择 CLI 与数据目录。本机常规读取使用原生 collector；可选配置工具和 SSH helper 需要 Python 3，远端支持 Python 3.6 及以上。Codex SSH 沿用已启用的 SSH 别名、已有主机密钥和免交互认证；可在设置中关闭。

Remote Control 任务通过本机 Codex 桌面端获取状态、TPS 与首输出延迟，无需在远端安装 Pacer。请保持 Codex 开启、连接远程主机并载入对应会话；未载入或断开的会话可能没有实时数据。设置中的“统计 Codex Remote Control 任务”默认开启，可独立于 SSH 关闭。重新连接时，历史 token 仅作为计数基线，不会显示为当前速度。进度显示当前阶段与本轮结束状态，没有完成百分比。

缓存或拆分上报的计数只更新统计基线，不产生新速度；完成后的迟到用量可补充已有卡片，不重复提醒。TPS 表示观察到的响应吞吐，网络合并事件会影响读数，不等同于模型解码速度。断线本身不会被视为输入或审批请求已解决，旧提醒可能保留到重新连接后的状态更新。

中途接入任务时，按累计计数估算的速度仍可能偏高，因为新上报的计数可能包含接入前的输出。这是上游现有估算方式的限制，不能据此判断模型的实际生成速度。

CLI 自动查找覆盖 Codex 应用（包括移动后的应用位置）、PATH、Homebrew、用户安装目录，以及 nvm、fnm、Volta、asdf、mise、pnpm 等常见位置。设置会显示检测到的实际文件；可以切换其他位置，或直接选择 Codex.app、codex 文件及其所在目录。指定的手动路径失效时会明确提示，不会悄悄换用另一份 CLI。“测试连接”会检查 CLI 启动、登录状态和额度接口，不会创建任务。

## Claude Code 来源

在“Claude 数据来源”中选择配置目录，默认 `~/.claude`，也支持 `CLAUDE_CONFIG_DIR`。修改目录后先保存，再点击“配置”启用可选监测。配置追加 Pacer hooks，并包装原有 status-line 命令，保留原始输入与显示输出，记录经过裁剪的额度数据。若已有 tracing exporter、endpoint 或认证 headers 冲突，则保留原配置，提示遥测尚未启用。新的 Claude Code 会话需要重新加载设置；仅看到“已配置”不表示一个已运行会话已经加载配置。

Stop hook 仅表示尝试结束；Pacer 需要通过父记录 ID 链确认停止结果属于当前提示词，且停止结果明确无 hook 错误、无追加上下文，才完成任务。只有 preventedContinuation=false 仍不足以确认结束；记录归属缺失时保持未确认，避免其他 Stop hook 继续任务时提前出现完成卡。日志缺失或采集中断会显示未确认状态，不会直接推断任务已中断。

启用“监听 SSH 任务”后，Claude 可使用 Codex 已启用的 SSH 别名；仅使用 Claude 的电脑可在“其他 SSH 主机”填入已有别名，以逗号、空格或换行分隔。Pacer 不保存 SSH 密码、不接受新的主机密钥，也不修改共享 provider 进程。SSH helper 只读已有来源；远端 hooks 与遥测需在远端配置中分别生效，本机配置成功不代表远端已经启用。冷启动或多个文件同时更新时，每次有界读取先处理 Pacer 自有 hooks 记录，再处理 transcript，让提示词归属先于引擎续写与结束记录建立。任务结束仍须有匹配的归属链和明确结束证据，不按静默或超时猜测。仅从可用 transcript 读取时，部分实时阶段、输入/审批、结束和性能信息可能仍缺失。

Claude 的准确请求时间来自匹配的 OTLP 数值记录；确认停止后，权威 transcript token 数和完整观察窗口可提供吞吐率估算。首输出延迟需要真实的流式显示回调或服务报告的 TTFT。Desktop SDK 与 `-p` 仅发送最终消息时，缺少数值遥测便保持未知，不用完成消息时间猜测首 token 时间。数值可能在请求结束后补到当前或保留卡片，不会因此重新出现已关闭的提醒。Codex 与 Claude 都保留测量的原始时间，旧速率变灰；额度显示不影响上方任务采集。

Claude 额度优先读取同账户新鲜 status-line 样本；没有新鲜样本时，使用 Pacer 独立 WebKit profile 中已有的 claude.ai 会话进行只读额度 GET。尚未建立会话时，点击“登录 Claude”，由用户在 Pacer 专用窗口完成正常网页登录及网站要求的验证。Pacer 不读取其他应用的 Keychain 或 Safe Storage，即使主动登录也不读取，也不导入 Claude、Safari 或 Chrome 的浏览器会话。

cookie 仅由 WebKit 管理，不另写到设置、JSON 或日志。账号属于多个组织时，需要明确选择对应组织，不会默认选择列表第一个。会话过期、退出或账户变化时，需在专用窗口重新登录；网络故障及 429 限流仍使用重试提示，不自动打开登录窗口。普通重新启动可复用仍有效的 WebKit 会话，但不保证网站会话永久有效，也不承诺所有版本或签名变更后的持久化结果。

既有 Pacer 自有 OAuth access-token 缓存、显式提供的环境变量或文件凭据，仅作为无网页会话时的安静兼容来源，不是主连接方式；不会借此弹出其他应用的钥匙串密码请求。设置中的来源标签和额度悬停提示说明当前渠道。网页额度接口属于私有、随版本变化的集成，不自动回退到 Desktop 历史记录。缺少重置日期时不推算倒计时、配速或周期曲线；服务未提供的 Credit、重置券或到期详情保持不可用。

## 界面语言

默认跟随 Mac 的首选语言，支持简体中文和英文；首选列表中没有这两种语言时使用英文。设置顶部的“语言”可选“跟随 macOS / 简体中文 / English”。语言变化时点击“保存并重新启动”，Pacer 会正常退出并重新打开设置，已有显示、数据来源和额度记录继续保留。Codex Pacer、Codex 等专有名词，以及任务原文和路径保持原样。

## 应用更新

首次安装包含更新器的版本后，Pacer 默认每天检查一次新版本。发现更新时会显示说明，点击安装后由应用完成下载、验证、替换和重启，保留原有设置与额度记录。更新 Pacer 不会终止 Codex 中正在运行的任务。

设置顶部的“应用更新”提供“检查更新”和自动检查开关；关闭自动检查后仍可手动更新。开关随设置页的“保存”生效。“检查更新”也可从应用菜单或启用后的菜单栏菜单打开。更新失败时，设置中会显示错误信息。

更新窗口打开时，灵动岛会自动收起，直到关闭或完成更新后恢复交互，避免遮挡更新按钮。后台检查没有发现新版本时，不会改变灵动岛的展开状态。

更新需要发布者提供有效签名的更新清单和安装包。未包含更新器的旧版仍需手动安装一次；更新源尚未发布或网络不可用时，不会把检查失败误报成已经是最新版。

## 灵动岛

悬停展开，移开收起。点击顶部或固定按钮可保持展开；Esc 收起。展开后的上方统一显示两个模块的任务，青绿色区分 Codex，暖橙色区分 Claude。同时启用两个模块时，下方展示两个服务的双圆环：圆环为剩余额度，白色刻度标出按时间均匀使用时应剩的位置，旁边标注充裕 / 正常 / 偏快；双模块时圆环显示 7d，5h 显示在环下一行，偏低或偏快时变为琥珀色，无需切换周期。运行中的任务显示本轮已运行时长；固定、设置及刷新 / 退出菜单位于任务标题右侧。只启用 Claude，或只启用 Codex 且已返回 5h 限制时，并排显示该服务的 5h 与 7d。仅启用 Codex，且主账户已返回额度限制但没有 5h 窗口时，恢复原来的额度条形展示，保留全部实际窗口，包括 8 小时或未知时长的限制；此时不显示 PRO 圆环。折叠时显示聚合任务数量、可用 TPS 与提醒，额度数值按服务颜色交替显示，双环同时显示两者，不相加或平均；悬停和辅助功能保留完整服务名称。

在双模块或仅启用 Claude 的圆环布局中，确认账户仅返回有效、未过期的每周限制时，5h 位置使用 PRO 标志；它是占位样式，不代表检测到付费套餐。缺少额度、重置时间或仅有模型专属每周限制时保留未知，不显示 PRO。尚未读取到实际额度时，不推断只有周限，仍显示未知状态。圆环采用更细的线条，环内突出额度数字与简短重置倒计时；完整重置日期、时间百分比、来源和更新时间在悬停提示及设置中查看，过期图标和错误操作仍明确显示。两个圆环独立处理未知值；没有重置时间就不填充时间环。展开区周期选择与设置中的折叠额度窗口选择独立；历史曲线始终在设置中查看。

任务行显示当前阶段与远程来源。Codex 点击可打开会话；非默认本机数据目录的任务链接可能不可用。Claude 优先打开已验证的 Desktop 会话映射；子代理可沿记录中的有效父会话 UUID，或同服务、同主机、同来源的已观测归属链导航到 UUID 根会话。即使父任务卡已不在列表，也须经过同样的会话映射或配置目录、SSH resume 检查，不会从子代理路径猜测父会话位置。默认配置目录的普通 CLI 会话可通过真实 Terminal 中的 `--desktop --resume UUID` 恢复。自定义 Claude 目录使用该目录对应的 `CLAUDE_CONFIG_DIR` 和 `--resume UUID`，避免误用默认账号；仅安装 CLI 或使用 SSH 时也通过 Terminal 恢复。打开不会发送提示词；任意 transcript UUID 不会伪造成 Desktop deeplink，远端路径不传回本机。实际跳转效果仍需在对应应用版本中验证。

少量任务时，展开面板按实际内容调整高度；超过 3 个任务后，任务区独立左右分页。使用页码两侧箭头或 Option + 左右方向键翻页，下方额度区保持原位，最后一页也不会改变面板高度。屏幕高度不足时，内容区仍可滚动，底部工具保持可见。

设置中的“显示模式”可选“自动 / 刘海 / 悬浮”。自动根据显示器是否有实体刘海选择布局；刘海模式贴在屏幕顶部，悬浮模式位于菜单栏下方。无实体刘海的显示器（包括非 Retina 显示器）也能手动选择刘海模式，不会留出摄像头空位。原有悬浮设置继续保留。

在“设置 → 折叠栏”中，顶部卡片包含实时预览、与折叠栏对应的左右布局条和宽度选项：拖动布局条中的组件调整顺序或换边，点 × 隐藏，组件过多时自动换行。下方按任务、性能、额度、警告分组，用开关显示或隐藏组件，每项附有说明；与组件相关的选项（单个任务的徽标显示、额度显示为剩余额度或配速）在开启后显示在该组件下方。灵动岛和悬浮模式都只有左、右两侧，始终一行，预览即时更新。点击一次“保存”即应用布局及当前设置，取消会丢弃本次布局编辑，“恢复默认”可还原原有布局。已有布局的中间组件会自动并入左侧。活动徽标合并状态与任务数：数字始终为进行中与待处理的任务数，运行时有服务色光弧环绕，需要你回复或审批时变为实心琥珀色，未读结束显示为对勾、叉或暂停，或在有任务运行时显示为角标；单个任务默认显示当前阶段图标，可在设置中改为显示数量。状态文字默认隐藏，可在任务分类中重新添加。最新 TTFT 仅显示秒数，在新测量到达前保留。额度/配速百分比及标签跟随设置中选择，剩余时间显示为当前额度窗口的百分比。额度数值在两个模块都启用时每 4 秒交替显示 Codex 与 Claude，只启用一个模块时显示该模块的百分比，可在设置中切换剩余额度或配速；额度双环同时显示两者（外环 Codex、内环 Claude）。两者默认开启。警告组件仅在 5h 额度低于 20%（空心「5h」）或耗尽（实心「5h」，均按服务着色）、额度更新延迟或 SSH 未连接时出现。旧布局中的子代理数量和操作组件会移除。自适应宽度随可见组件收窄或扩展；指定宽度仍使用同一个滑块，真实刘海会预留摄像头空间。展开面板上方任务与下方额度独立，隐藏组件不会关闭任务监听或额度采集。

在设置中的各服务“额度历史”查看周期曲线、来源与更新时间；“额度详情”保留其他限制窗口、配速、Credit 与重置券。各模块分别保存账户与曲线，曲线只记录已知重置日期的当前七天周期。Codex 可用 banked reset 若在当前周期内到期，会在曲线对应日期显示时钟标记；悬停或点击查看到期信息。

点击“x 次重置”可展开到期详情，再次点击收起。列表按到期先后显示具体日期、时间和次数，也包括七天曲线之外的到期时间。时间使用本地时区，时区名称显示在列表下方；服务未提供的详情显示“到期时间未知”，明确不过期的重置券单独列出。到期或额度刷新后，展开的列表会同步更新。

本轮结束与中断卡片默认保留 30 分钟。可设为 5、15、30、60、240 分钟或“直到点击”。点击后成功打开 Codex 会话或已验证 Claude Desktop 目标，才移除对应卡片，正常重启后仍保持已读。成功打开已结束的父会话时，只同步确认点击时已捕获、同来源且归属链也已结束的子代理卡片；打开完成后仍须匹配原来的轮次与结束状态。仍在运行、稍后才结束、已进入新轮次、父子归属或来源已改变的子代理不会被清除。Claude 的 Terminal resume 回退或打开失败会保留卡片。状态变化或保留时间到期也会移除卡片。展开或悬停不会清除未查看的提示。

菜单栏显示默认关闭，可在设置中开启。齿轮始终可打开设置，电源按钮退出。系统通知需 macOS 授权；未授权时仍可使用灵动岛提醒。

## 数据不可用时

读取失败会显示状态与提示，不会把旧数据显示为实时结果。输出速度尚无有效样本时不显示数值；采样停顿后保留灰色估算值。重连、账户切换和新的任务轮次会更新对应状态。

额度读取失败时，展开面板会直接显示失败步骤、具体原因、可用的错误码，以及 CLI 和 Codex 数据目录；无需悬停查看。可点击“重新检测并重试”或打开设置测试连接。若仍保留上次成功读取的数据，会注明其读取时间。错误中的凭据和账户标识会被隐藏。API Key、Amazon Bedrock 等登录方式不提供 ChatGPT 订阅额度，界面会说明这一点。

部分 Codex 客户端或未来协议版本可能无法提供实时事件，Pacer 会使用日志兜底。连接成功不代表能观察所有客户端任务。“本轮结束”只表示该轮对话结束。

只有一个 SSH 来源未连接时，展开区会显示其名称；多个来源未连接时，显示“X 个 SSH 未连接”。点击该提示可打开设置，在“数据来源 → 监听 SSH 任务”下查看所有未连接的 SSH 名称与状态。Pacer 会自动重试连接。

如需反馈，请附应用版本、macOS 版本、来源类型和复现步骤；截图前隐藏私密任务标题与账户信息。
