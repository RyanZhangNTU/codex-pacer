Codex Pacer 3.3.0 shows which model each task is using, in a tidier task row.

- **Model and reasoning effort:** every expanded task row names the model behind the current turn and its reasoning effort, below the output speed in the service's color, such as **GPT-6.1 Sol High** or **Opus 5.5 XHigh**. Hover over it for the full identifier. This works for Codex and Claude Code on this Mac, SSH hosts and Remote Control.
- **Always the turn that ran:** a model or effort changed in the middle of a turn appears with the next turn, and the row shows the service name until the model is known.
- **Turn time:** next to the speed, each row shows how long the turn has been running, or how long it took once it ends. Time to first output now lives in the speed's tooltip.
- **Calmer list:** status icons are simple outlines, long titles no longer widen the panel, and endings you have already seen fade back so running and waiting tasks stand out. Unread endings and failures keep their color.

### Install

- **Existing installation:** use **Check for Updates** to update in place. Your preferences are preserved.
- **Manual installation:** quit Codex Pacer, replace the copy in Applications with the new app, then open it again.
- Requires macOS 14 or later.

See the [user guide](https://github.com/RyanZhangNTU/codex-pacer/blob/main/docs/guide.md) and the [full changelog](https://github.com/RyanZhangNTU/codex-pacer/blob/main/CHANGELOG.md).
