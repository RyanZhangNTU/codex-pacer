Codex Pacer 4.2.4 lets you move the island anywhere on the Mac and on Windows, keeps hover pop-ups to the toolbar, and fixes Claude Code subagents that stayed marked as running.

- **Move the island anywhere.** Drag its status bar to a spot that works for you, or release it near a screen edge to snap it in place. When it sits low on the screen it opens upward. Free Move replaces the fixed positions in Settings → Appearance, which also has **Return to Top Center**.
- **Calmer hovering.** Only the toolbar buttons at the top of the open island show tooltips; task rows, quota rings and the DeepSeek wallet no longer pop up text under the pointer. Screen readers still read every description.
- A Claude Code subagent that finishes while its chat is still working no longer stays marked as running after the chat ends, and the speed keeps updating while only subagents are working.
- Other bug fixes and stability improvements.

See the [user guide](https://github.com/RyanZhangNTU/codex-pacer/blob/main/docs/guide.md) and the [full changelog](https://github.com/RyanZhangNTU/codex-pacer/blob/main/CHANGELOG.md).
