适用于 macOS 14 及以上，Apple Silicon / Intel 通用。

- 增加完整中英文界面。默认跟随 Mac 的首选语言，也可在设置中选择语言，保存后自动重启应用。
- 增加应用内更新：默认每天检查新版本，点击安装后完成下载、安装和重启。也可在设置中手动检查或关闭自动检查。
- 所有显示器均可选择自动、刘海或悬浮显示模式。
- 任务超过三个时按页切换，额度区域保持可见。
- 自动查找更多位置的 Codex CLI，支持手动选择与连接测试。
- 额度读取失败时直接显示原因、错误码及处理建议。

已包含更新器的版本可通过“检查更新”安装本次更新。尚未包含更新器的旧版需手动安装一次：下载 DMG，退出旧版后拖入 Applications 覆盖安装。

如下载的是未签名版，首次打开被 macOS 拦截时，请到“系统设置 → 隐私与安全”页面最下方的“安全性”，选择“仍要打开”，再重新打开安装包或应用。
