For macOS 14 or later, with support for Apple Silicon and Intel.

- Use Codex Pacer in English or Simplified Chinese. The default follows your Mac's preferred languages; choose a language in Settings and save to relaunch.
- Check for updates inside the app. Pacer checks daily by default; download, installation and relaunch start when you choose to install. You can also check manually or turn off automatic checks in Settings.
- Choose Automatic, Notch or Floating on any display.
- Browse tasks three at a time while keeping quota visible.
- Find Codex CLI in more installation locations, choose it manually, and test the connection in Settings.
- See the cause, error code and next steps when quota cannot be loaded.

Versions that already include the updater can install this release through Check for Updates. Earlier versions need one manual installation: download the DMG, quit the old app, and drag Codex Pacer into Applications.

For the unsigned release, if macOS blocks the first launch, open System Settings → Privacy & Security, scroll to Security, choose Open Anyway, then reopen the installer or app.
