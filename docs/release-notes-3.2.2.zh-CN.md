Codex Pacer 3.2.2 可以直接从灵动岛打开 Codex 或 Claude，并让两者同时运行时的任务徽标更顺滑。

- **应用按钮：** 展开灵动岛后，任务标题栏中“全部标为已读”旁新增 Codex 和 Claude 按钮，显示为各自服务的颜色。即使没有任务在运行，点击也会把对应的桌面版切到前台。未安装桌面版的服务不显示按钮；可在“设置 → 通用 → 显示应用按钮”中关闭。
- Codex 和 Claude 同时运行时，任务徽标周围的两道光弧都有清晰的头部，各自位置固定；某个服务开始或结束时，对应的光弧会平滑地长出或淡出。

### 安装

- **已有安装：** 通过“检查更新”原地升级，保留现有设置。
- **手动安装：** 先退出 Codex Pacer，再用新版替换“应用程序”中的副本，然后重新打开。
- 需要 macOS 14 及以上。

详见[使用指南](https://github.com/RyanZhangNTU/codex-pacer/blob/main/docs/guide.zh-CN.md)和[完整更新记录](https://github.com/RyanZhangNTU/codex-pacer/blob/main/CHANGELOG.md)。
