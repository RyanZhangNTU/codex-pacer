For macOS 14 or later, with support for Apple Silicon and Intel.

- Keep update dialogs accessible when the island is expanded or pinned. The island collapses while update controls are open and resumes interaction when they close.
- Restore the exact top-edge position in Notch mode after dismissing an update, fixing a position shift found in 2.1.2.

Install from Settings → Check for Updates. If an older version already has a hidden dialog, press Return to dismiss it, collapse the island, then check again from Settings with the pointer away from the island.

For a manual installation, quit the old app and drag Codex Pacer from the DMG into Applications. For the unsigned release, if macOS blocks the first launch, open System Settings → Privacy & Security, scroll to Security, choose Open Anyway, then reopen the installer or app.
