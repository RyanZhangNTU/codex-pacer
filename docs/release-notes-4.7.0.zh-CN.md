**Claude 可以请 Codex 帮忙了**。在“设置 → 协作”（Beta）打开“Claude 调用 Codex”，然后直接跟 Claude 说，比如“让 Codex 审查一下这次改动”。Pacer 按你的设置启动 Codex，在 Claude 任务下实时显示进度，这一轮结束后自动清理。
