# Windows 设置页对照

P3d 逐项对照了 Mac 的 11 个 `SettingsPane`，以当前 C 通道的固定基线为准。Mac 的偏好键、保存格式和默认调用路径均未修改。Windows 继续使用 schema 2；收起栏的界面 ID `collapsed` 对应 Mac 的 `collapsedBar`。

| 页面 | 对照结果与本次处理 | 统一集成时检查 |
| --- | --- | --- |
| 通用 | 已有版本、登录启动及系统禁用状态、语言和重启、隐藏项目名、应用按钮。更新按钮和自动检查仍为占位。 | 更新功能由 B 通道接入；确认保留登录启动、语言保存失败和恢复断言。 |
| 外观 | Black/Glass、位置、显示器和全屏开关已有。新增系统透明效果设置入口；状态读取 P3c 注入的同一系统快照；仅 DeepSeek 开启时隐藏展开额度样式，与 Mac 一致。 | 注入透明效果/高对比度变化后，设置说明与岛同步；取消 Glass 偏好不会被系统回退改写。 |

## 验证范围

按“先写完、再统一测试”的流程，本轮只做 Debug 引擎/桌面零警告编译和定向单元测试。`Pacer.PresentationTests --unit-only` 在创建 `Application`、引擎和窗口之前退出；设置页单元测试使用假的链接启动器和分享后端，不打开浏览器、系统设置或系统分享界面。

定向测试覆盖 Help 默认服务、DeepSeek 单服务行、双语价格文档链接、固定 Windows 设置入口、启动失败、分享链接校验、重复调用、失败和释放后的拒绝。实际页面滚动、焦点、UIA 和完整展示矩阵留给集成阶段，当前不把这些新交互记为实机通过。原有展示与引擎断言全部保留。

系统分享按 Microsoft 的 [桌面 WinRT 窗口互操作说明](https://learn.microsoft.com/en-us/windows/apps/develop/ui/display-ui-objects#for-classes-that-implement-idatatransfermanagerinterop) 获取所属窗口的 `DataTransferManager`，通过 `ShowShareUIForWindow` 显示。点击分享前不创建系统分享对象；C 通道不会选择接收者或自动发送内容。
