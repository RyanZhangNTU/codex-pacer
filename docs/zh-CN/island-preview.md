# Codex Pacer 状态岛预览版

新版采用 SwiftUI 和 AppKit，聚焦本机任务活动与当前账户额度。历史图表、API 价值和订阅回本不再进入新版界面。

## 启动

需要 macOS 14 或更新版本，以及带 Swift 5.10 或更新工具链的 Xcode。

```sh
npm run island:test
npm run island:build
open "output/island-preview/Codex Pacer Island.app"
```

鼠标悬停时展开，移开后收起；点击顶部或固定按钮可以保持展开。菜单栏左键切换展开状态，右键提供刷新、设置和退出。设置中可以选择显示器、悬浮胶囊、全屏显示和 Codex 数据目录。

构建产物只用于本地测试，采用临时签名，尚未公证。预览版使用独立应用标识，不迁移旧版数据库。

## 数据如何解释

额度来自当前本地 Codex 登录账户，可能包含其他设备的使用。界面显示剩余比例和服务器返回的重置时间。读取失败时保留上次额度并标记时间；字段缺失显示暂不可用。

任务活动来自本机近期日志，最多读取 16 个文件，每个文件首次或补读最多 128 KiB。只有明确的开始、结束和中断事件才改变任务状态。三分钟没有新事件时显示未确认，任务结束也不代表工作成功。

本次预览尚未接入可靠的等待审批信号，也不汇总远程任务。开发文档与验证步骤见 [原生包说明](../../native/README.md)。
