# Codex Pacer 状态岛预览版

新版采用 SwiftUI、AppKit 和 Swift Charts，聚焦任务交互、当前账户额度与配速。历史使用分析、API 价值和订阅回本不进入新版。

## 启动与交互

需要 macOS 14 或更新版本，以及带 Swift 5.10 或更新工具链的 Xcode。

~~~sh
npm run island:test
npm run island:build
open "output/island-preview/Codex Pacer Island.app"
~~~

悬停展开，移开后收起；点击顶部或固定按钮可以保持展开。展开后，任务、额度与曲线显示在同一面板，不再切换标签。任务卡片显示会话名称、执行阶段和来源主机，点击直接打开对应的本机或 SSH 会话。顶部速度合计所有运行任务。

展开和收起使用连续的阻尼动画，宽高同步变化，顶部位置保持固定。文字与图表保持正常尺寸，随空间展开逐渐显现；快速反向时保留当前速度，避免突然停顿。动画适配所选屏幕的刷新率，静止时停止逐帧更新；开启系统“减少动态效果”后直接切换到最终状态。 刘海贴边的液态玻璃模式先淡出顶部黑色块再展开；折叠到位后再淡入黑色块。快速反向操作会接续当前透明度，悬浮胶囊和经典模式保持原有展开节奏。

主界面只显示任务、额度、配速和曲线。数据来源与计算说明收在设置的折叠项里。

菜单栏图标默认隐藏，可在“设置 → 显示 → 在菜单栏显示”中开启，保存后立即生效，并在下次启动时保留选择。隐藏后仍可从灵动岛底部的齿轮按钮打开设置；底部的电源按钮和设置中的“退出 Codex Pacer”按钮均可退出应用。启用时，菜单栏左键切换展开状态，右键提供操作。设置还可选择显示器、悬浮胶囊、全屏显示、额度窗口、配速百分比、提醒和 Codex 数据目录。

构建产物用于本地测试，采用临时签名，尚未公证。预览版使用独立应用标识。

## 任务状态与 token/s

本机与 Codex 已配置的 SSH 任务通过实时订阅更新。日志仅用于启动补全和低频兜底，不监听文件变化。开始事件或轮次上下文确认当前轮次，只有匹配的结束事件才能让它进入空闲状态；工具调用与返回提供最近阶段。autoreview 不进入任务列表、状态和吞吐统计。只有同步等待输入的工具调用会显示等待回复，异步提问不会暂停任务。

已经观测到的运行任务会保持状态，直到匹配的轮次结束；长工具调用不会因沉默三分钟而自动消失。启动时，缺少近期证据的旧日志显示未确认。一轮回复结束后，卡片显示“本轮结束”。缺失轮次开始事件时不会仅凭结束事件判定完成。全局等待审批和 Windows 远程控制任务尚未接入。

结束或中断的任务默认保留 30 分钟；设置可选 5 分钟、15 分钟、1 小时、4 小时或“直到点击”。点击卡片、任务状态变化或保留时间到期后，结束记录移出列表。源文件暂时离开采集范围时，已观测到的结束记录仍会保留。

折叠岛用勾号和数量提示未查看的结束轮次，中断时显示暂停图标。点击提示直接打开最新结束的会话；悬停和展开不会清除提示。多条结束记录逐条处理，开始新一轮后仍可再次提醒。启动时不重放旧的结束提醒。可在设置中关闭结束提醒，任务保留规则仍然有效。

token/s 合计运行中任务的近期输出 token 增量，排除输入 token 和 autoreview，不随点击会话而变化。它扣除可确认的工具阻塞时间，仍可能包含网络与计数上报延迟，不等于模型端的精确生成速度。采样停顿时保留灰色估算值；首次采样前，折叠时隐藏速度和单位，展开时显示“采样中”。新轮次、计数回退或轮次结束会清除上一轮估算。

## 实时订阅

本机优先连接已有 app-server 端点；当前桌面端没有该端点时，使用已验证的 Desktop IPC。SSH 使用已有 app-server 的 Unix WebSocket。两者都保持连接，事件直接更新任务面板，不再频繁扫描日志。设置显示已连接来源和订阅的运行会话数。

可确认的工具等待期间速度为 0；后台工具运行时，若收到模型生成事件则继续计算。中途订阅先建立计数基线。任务按来源与 UUID 去重，只有当前轮次的明确结束状态才显示“本轮结束”。增量版本缺口会撤回该流的状态并重新同步。

启动时补全日志；正常连接下每 120 秒发现未覆盖会话，断线时每 60 秒补全。已由事件确认的运行会话不再读取对应日志。当前桌面内部协议依赖应用版本，不兼容时由日志兜底。

[订阅说明与验证结果](realtime-experiment.md)包含诊断命令和接入范围。

## SSH 任务

应用读取 Codex 中已启用的 SSH 别名，使用现有 OpenSSH 登录配置和 Python 3，只采集会话名称、状态、执行阶段与输出计数。远程对话正文、工具内容与认证数据不会传回。任务行标明来源主机，运行数量和 token/s 合计本机与 SSH 任务，继续排除 autoreview。

连接失败时显示简短提示，并自动重试。设置可关闭 SSH 统计；应用退出或睡眠时关闭自己的监听连接，不改动远程 Codex 进程。

## 配速与当前窗口曲线

配速沿用原版公式：剩余额度百分比 ÷ 剩余时间百分比 × 100。100% 表示与均匀配速一致；85% 以下需要放慢，115% 以上表示额度较充裕。到期或过期数据不再提供实时配速。

每次有效刷新记录当前 7 天窗口的剩余额度。普通周期切换和提前重置都会开始新曲线；旧窗口数据不会混入新窗口。曲线最多保留 7 天，不建立历史周期分析或导入旧版数据库。

图中的实线是实际采样，虚线是均匀配速参考；悬停可查看采样时间与额度。曲线省去重复标题与常驻图例，日期处的悬停提示解释线条含义。应用从首次采样开始记录，不补造窗口开始时的 100% 额度。曲线会本地保存，重启后只有核实同一工作区才能恢复；切换账户后重新记录。

读取失败时保留最后有效额度并标记时间，不添加新采样。账户额度可能包含其他设备的使用，不能归因于所选任务。

## 额度进度与账户余额

单条进度条表示剩余额度，细刻度标出按时间均匀使用时应剩的额度；下方只保留重置倒计时与配速。过期或不可用数据不显示刻度。倒计时遵循服务返回的当前重置时间。

账户信息合并为一行，显示可用重置次数与剩余 credit。悬停重置次数可查看可用券中最早的精确到期时间，三天内到期时用颜色提醒。次数读取服务汇总，不能用券明细条数替代；明细不完整时，提示标为“已知最近到期”。余额读取服务值，缺失时显示不可用，不用 token 或 API 价格推算。

[重置券](https://help.openai.com/en/articles/20001498-how-banked-codex-resets-work)与[付费 credit](https://help.openai.com/en/articles/12642688-using-credits-for-flexible-usage-in-chatgpt-personal-plans)分别显示。应用只读取信息，不执行重置或充值。

## 提醒与验证

低额度和等待回复默认在状态岛提示；本轮结束提醒可自行开启。系统通知默认关闭，启用后由 macOS 请求授权。隐藏项目名称会同时作用于界面和新提醒。

验证重点包括悬停、固定、外部点击收起、键盘焦点、设置保存、多屏、全屏和睡眠唤醒。重置逻辑由模拟数据测试，真实服务连接单独验证。
