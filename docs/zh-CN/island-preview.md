# Codex Pacer 状态岛预览版

新版采用 SwiftUI、AppKit 和 Swift Charts，聚焦任务交互、当前账户额度与配速。历史使用分析、API 价值和订阅回本不进入新版。

## 启动与交互

需要 macOS 14 或更新版本，以及带 Swift 5.10 或更新工具链的 Xcode。

~~~sh
npm run island:test
npm run island:build
open "output/island-preview/Codex Pacer Island.app"
~~~

悬停展开，移开后收起；点击顶部或固定按钮可以保持展开。任务页支持选择会话，查看最近执行阶段和输出速度。默认本地数据源可以打开所选 Codex 会话。

主界面只显示任务、额度、配速和曲线。数据来源与计算说明收在设置的折叠项里。

菜单栏左键切换展开状态，右键提供操作。设置可选择显示器、悬浮胶囊、全屏显示、额度窗口、配速百分比、提醒和 Codex 数据目录。

构建产物用于本地测试，采用临时签名，尚未公证。预览版使用独立应用标识。

## 任务状态与 token/s

任务状态来自本机近期日志。明确的开始、结束和中断事件决定任务状态；工具调用与返回提供最近阶段。只有同步等待输入的工具调用会显示等待回复，异步提问不会暂停任务。

三分钟没有新事件时显示未确认，同时保留最后观测到的等待状态。任务结束不代表工作成功。全局等待审批和远程任务尚未可靠接入。

token/s 使用本地输出 token 的增量估算，排除输入 token。这个值包含报告间隔内的等待和工具耗时，不等于模型端的精确生成速度。样本不足、计数回退或 15 秒没有更新时显示不可用。

## 配速与当前窗口曲线

配速沿用原版公式：剩余额度百分比 ÷ 剩余时间百分比 × 100。100% 表示与均匀配速一致；85% 以下需要放慢，115% 以上表示额度较充裕。到期或过期数据不再提供实时配速。

每次有效刷新记录当前 7 天窗口的剩余额度。普通周期切换和提前重置都会开始新曲线；旧窗口数据不会混入新窗口。曲线最多保留 7 天，不建立历史周期分析或导入旧版数据库。

图中的实线是实际采样，虚线是均匀配速参考。应用从首次采样开始记录，不补造窗口开始时的 100% 额度。曲线会本地保存，重启后只有核实同一工作区才能恢复；切换账户后重新记录。

读取失败时保留最后有效额度并标记时间，不添加新采样。账户额度可能包含其他设备的使用，不能归因于所选任务。

## 提醒与验证

低额度和等待回复默认在状态岛提示；任务结束提醒可自行开启。系统通知默认关闭，启用后由 macOS 请求授权。隐藏项目名称会同时作用于界面和新提醒。

验证重点包括悬停、固定、外部点击收起、键盘焦点、设置保存、多屏、全屏和睡眠唤醒。重置逻辑由模拟数据测试，真实服务连接单独验证。
