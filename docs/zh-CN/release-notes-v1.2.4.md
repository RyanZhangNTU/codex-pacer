# Codex Pacer v1.2.4

此开发版本新增 GPT-6.1 Sol、GPT-6 Sol 和 GPT-6 Luna 支持，尚未发布到 GitHub Releases。

## 模型价格

以下内置价格已于 2026 年 10 月 1 日对照 [OpenAI Standard API 价格表](https://developers.openai.com/api/docs/pricing)核实，单位为美元／百万 token。

| 模型 | 输入 | 缓存输入 | 输出 |
| --- | ---: | ---: | ---: |
| GPT-6 Astra | $10.00 | $1.00 | $50.00 |
| GPT-6.1 Sol | $2.00 | $0.10 | $10.00 |
| GPT-6 Sol | $2.00 | $0.20 | $10.00 |
| GPT-6 Luna | $0.10 | $0.01 | $0.50 |
| GPT-5.6 Sol | $4.00 | $0.40 | $20.00 |
| GPT-5.6 Terra | $2.00 | $0.20 | $12.00 |
| GPT-5.6 Luna | $0.20 | $0.02 | $1.20 |

新增模型有对应的显示名称和图表颜色。标准模型 ID 和合法的日期后缀 ID 使用同一模型价格。GPT-5.6 系列内置价格同步更新；不带型号后缀的 GPT-5.6 别名继续使用 Sol 价格。

API 等价价值仍按 Standard 短上下文价格估算，不包含缓存写入费用、长上下文价格或速度档位费用。该数值不能作为 API 账单或订阅 credit 消耗量。

## 升级行为

升级后首次启动会重算已有用量的 API 等价价值。这也覆盖此前无法计价的 GPT-6 日期后缀模型，即使在线价格目录已经包含对应的标准模型。token 数量、会话、配额历史和设置保持不变。后续启动会跳过已完成的修复，除非价格目录发生变化。

在线刷新取得的官方价格仍优先于内置备用价格。已知误用长上下文输出价格的条目会自动修复；其他已保存的官方价格会保留，直到下一次在线刷新。

## 一并包含的修复

- 修复 macOS 27 菜单栏点击，正常打开用量弹窗和右键菜单
- Windows 托盘弹窗使用物理点击坐标选择显示器，适配不同缩放比例
- 重新打开已调整尺寸的托盘弹窗时，先恢复初始尺寸再显示

应用名称、bundle identifier 和本地数据位置保持不变。
