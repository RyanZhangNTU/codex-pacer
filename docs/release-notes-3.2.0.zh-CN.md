Codex Pacer 3.2.0 可以自己决定岛的位置，没有刘海的 Mac 也能把它作为细竖条停靠在屏幕角落。

- “设置 → 外观”现在提供“刘海”和“自定义”。选择“自定义”后可以设置“屏幕位置”：居中放在菜单栏下方，或作为细竖条贴着屏幕侧边停靠在任一角落。
- 停靠的竖条会把折叠栏组件竖向排列，展开面板在竖条旁边打开。
- Claude Desktop 用下一步提示框结束一轮后，任务不再一直显示为运行中，而是显示为已结束，并提醒你回复。

### 安装

- **已有安装：** 通过“检查更新”原地升级，保留现有设置。
- **手动安装：** 先退出 Codex Pacer，再用新版替换“应用程序”中的副本，然后重新打开。
- 需要 macOS 14 及以上。

详见[使用指南](https://github.com/RyanZhangNTU/codex-pacer/blob/main/docs/guide.zh-CN.md)和[完整更新记录](https://github.com/RyanZhangNTU/codex-pacer/blob/main/CHANGELOG.md)。
