适用于 macOS 14 及以上，支持 Apple Silicon 和 Intel。

- 自定义单行折叠栏：按任务、性能、额度、警告分类选择组件，拖动调整顺序及左、右位置，预览即时更新，一次保存即可生效。
- 自适应宽度随可见组件调整。支持保存、取消和恢复默认布局，展开后的任务与额度面板保持原有布局。
- 修复嵌套工具调用后的巨额 TPS，保留准确请求记录的纠正结果及原始测量新鲜度时间。
- 修复 Python 3.6 主机的远端日志日期解析，避免日志扫描异常阻塞心跳或反复空转占用 CPU。
- 任务数使用数字徽标，最新 TTFT 仅显示秒数；额度/配速与剩余时间显示百分比，低额度、更新延迟和 SSH 警告仅在异常时显示。

手动安装时先退出旧应用，再将 DMG 中的 Codex Pacer 拖入 Applications。未签名发行版如被 macOS 阻止，请在“系统设置 → 隐私与安全性 → 安全性”选择“仍要打开”，再重新打开安装包或应用。
