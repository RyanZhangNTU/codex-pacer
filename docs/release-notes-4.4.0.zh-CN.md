**组件随心增删、排序。**展开面板和折叠栏都能按你的习惯添加、删除、排序组件，比如展开时只显示任务、不显示额度。点一项看它的设置，用末尾的圆形按钮加入或移除。

**折叠栏品质升级。**大小可调，位置按屏幕分别记住，组件也支持更多功能。

**外观全面焕新。**新增多种材质，动画细节也升级了。

**识别 Codex Dot 管理的任务。**首次使用需要重启 Codex。Dot 任务在云端运行，目前只显示进度，暂时无法识别速度。Windows 上需要 Microsoft Store 版 Codex。

**修复。**用第三方 API 时 Codex 进度圆环也会走；Claude 任务结束后不再一直显示「正在处理任务」，并能和你已有的 Claude Code 遥测设置共存；修复了 Windows 10 上的崩溃，引擎意外停止时会留下崩溃报告，方便反馈。
