Codex Pacer 3.3.0 在更清爽的任务行中显示每个任务正在使用的模型。

- **模型与推理强度：** 展开后的每个任务行都会在输出速度下方，用服务的颜色显示本轮使用的模型和推理强度，例如“GPT-6.1 Sol 高”或“Opus 5.5 极高”。将指针停在上面可查看完整标识。本机、SSH 主机和 Remote Control 上的 Codex 与 Claude Code 任务都支持。
- **始终对应实际运行的轮次：** 在一轮进行中途更改模型或推理强度，会从下一轮开始显示；在模型确定之前，任务行显示服务名称。
- **本轮用时：** 每行在速度旁显示本轮已进行多久，结束后显示总耗时。首输出时间移到了速度的悬停提示中。
- **列表更安静：** 状态图标改为线稿，过长的标题不再撑宽面板，已查看的结束任务会变淡，让运行中和等你处理的任务更醒目。未读的结束任务和失败任务保持原有颜色。

### 安装

- **已有安装：** 通过“检查更新”原地升级，保留现有设置。
- **手动安装：** 先退出 Codex Pacer，再用新版替换“应用程序”中的副本，然后重新打开。
- 需要 macOS 14 及以上。
