Windows 上，在 Codex 应用以外（例如终端里）运行的 Codex 任务恢复即时更新，不再最多晚两分钟。Mac 和 Windows 上，结束前输出很长的 Codex 任务现在会显示为已完成，不再显示“状态未确认”。

三个服务并排显示时，额度圆环下的“重新检测并重试”和“设置”按钮不再被截断。
