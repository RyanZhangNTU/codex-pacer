Codex Pacer 4.2.4 在 Mac 和 Windows 上都可以把灵动岛拖到任意位置，悬停提示只留在工具栏，并修复了 Claude Code 子代理在结束后仍显示为运行中的问题。

- **灵动岛可以自由移动了。** 按住状态栏，把灵动岛拖到顺手的位置；靠近屏幕边缘松手，它会贴边。放在屏幕下方时，面板会向上展开。“设置 → 外观”里的固定位置改为“自由拖动”，也可以选“回到顶部中央”。用键盘时，选“更多 → 移动灵动岛”，再用方向键移动，按 Enter（Mac 上为 Return）确认，按 Esc 取消。
- **悬停更安静。** 展开后只有顶部工具栏的按钮会显示提示；任务行、额度圈和 DeepSeek 钱包不再在鼠标下弹出文字。读屏软件仍会读出所有说明。
- **欢迎页教你移动灵动岛。** 悬停、移开和拖动三个手势并排说明；帮助页也新增了“移动灵动岛”一项。
- 对话还在进行时结束的 Claude Code 子代理，不会在对话结束后一直显示为运行中；只有子代理在工作时，速度也会继续更新。
- Windows 上可以开启“SSH 主机未连接”提醒；在早于 UTC 的时区里，午夜后新开的 Codex 会话也会立即显示。

更多信息见[使用说明](https://github.com/RyanZhangNTU/codex-pacer/blob/main/docs/guide.zh-CN.md)和[完整更新记录](https://github.com/RyanZhangNTU/codex-pacer/blob/main/CHANGELOG.md)。
