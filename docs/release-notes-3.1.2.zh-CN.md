Codex Pacer 3.1.2 会在启动任务的应用中打开任务，也能识别第三方应用发起的 Claude 和 Codex 任务。

- 在终端、编辑器或 Zotero 插件等内嵌 Claude 或 Codex 的应用中启动的任务会标出应用名称，点击即可直接切换到该应用。
- 可在“设置 → Claude”和“设置 → Codex”中隐藏这些应用中的会话，默认显示。
- 不再显示 Zotero Agent 插件的翻译请求。
- 回答过的 Claude 问题和审批不再一直显示为等待中。

### 安装

- **已有安装：** 通过“检查更新”原地升级，保留现有设置。
- **手动安装：** 先退出 Codex Pacer，再用新版替换“应用程序”中的副本，然后重新打开。
- 需要 macOS 14 及以上。

详见[使用指南](https://github.com/RyanZhangNTU/codex-pacer/blob/main/docs/guide.zh-CN.md)和[完整更新记录](https://github.com/RyanZhangNTU/codex-pacer/blob/main/CHANGELOG.md)。
