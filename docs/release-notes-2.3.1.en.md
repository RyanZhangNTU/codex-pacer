For macOS 14 or later, with support for Apple Silicon and Intel.

- Show the running subagent count on the parent task, with TPS summed across the parent and its running subagents.
- Keep the last measured TPS across tools and new turns. Fresh values stay white for 15 seconds and then turn gray; folded totals include retained rates.
- Keep first-output latency stable throughout a turn and restore SSH timing from live events or service-reported measurements.

Install from Settings → Check for Updates. For manual installation, quit the old app and drag Codex Pacer from the DMG into Applications. If the unsigned release is blocked, use System Settings → Privacy & Security → Security → Open Anyway, then reopen the installer or app.
