适用于 macOS 14 及以上，支持 Apple Silicon 和 Intel。

- 改进 TPS 统计：使用单次请求已结算的真实用量，增量读取本地和 SSH 的统计记录；用量报告间隔较长及任务完成后保留最近测得的均速。
- 每个任务展示观测首输出延迟，以首次收到模型文本或推理文本为准。
- 设置中新增“省电 / 均衡 / 更及时”展示更新选项；默认均衡沿用原有间隔，各模式的用量精度相同。

通过“设置 → 检查更新”安装。

手动安装时，先退出旧应用，再将 DMG 中的 Codex Pacer 拖入 Applications。未签名发行版如被 macOS 阻止，请打开“系统设置 → 隐私与安全性”，滚动到“安全性”，选择“仍要打开”，然后重新打开安装包或应用。
