Codex Pacer 3.0.1 已使用 Developer ID 签名，并通过 Apple 公证。功能与 3.0.0 相同。

### 安装

- **从 3.0.0 升级：** 照常使用“检查更新”，Pacer 会原地更新并自动重新打开。
- **全新安装：** 把 DMG 中的 Codex Pacer 拖入“应用程序”后打开。macOS 会询问一次是否打开从互联网下载的应用，点击“打开”即可，不再需要到系统设置中选择“仍要打开”。
- 需要 macOS 14 及以上，支持 Apple 芯片和 Intel。

详见[使用指南](https://github.com/RyanZhangNTU/codex-pacer/blob/main/docs/guide.zh-CN.md)和[完整更新记录](https://github.com/RyanZhangNTU/codex-pacer/blob/main/CHANGELOG.md)。
