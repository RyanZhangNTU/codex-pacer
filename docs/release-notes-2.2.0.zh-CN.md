适用于 macOS 14 及以上，Apple Silicon / Intel 通用。

- 本机事件订阅改为原生采集，跳过对话正文并限制历史数据保留，降低采集开销。
- 七天额度曲线每五分钟保留一个采样点，每三十分钟合并保存。实时任务／token 更新及额度读取频率保持原状；账号或周期变化、睡眠、正常退出时仍立即保存。
- 改进本机与 SSH 任务发现；订阅释放、会话卸载后保留完成提醒；带点号的 SSH 主机别名也能直接通过实时事件识别任务。
- 工作继续进行时持续显示待回复／审批提醒。单任务显示当前阶段，多任务显示明确数量，并采用已确认的原生状态图标。
- 修复新轮次 token/s 虚高及旧数值停留：每轮独立建立计数基线，十五秒没有新计数就撤下过期数值。
- 保留现有设置，改进重连、会话打开失败、失败状态提示及额度窗口选择。

异常退出可能丢失最后三十分钟的本地曲线。

可从“设置 → 检查更新”安装。

手动安装时，请先退出旧版，再将 DMG 内的 Codex Pacer 拖入 Applications。如未签名版首次打开被 macOS 拦截，请到“系统设置 → 隐私与安全”页面最下方的“安全性”，选择“仍要打开”，再重新打开安装包或应用。
