适用于 macOS 14 及以上。本次 2.2.0 候选版本用于本地测试，尚未发布到自动更新源。

- 修复会话刚开始时 token/s 虚高及旧数值长时间停留：每轮独立建立计数基线，累计过密更新，忽略上一轮延迟用量；15 秒未收到新计数就撤下数值，界面到期刷新不增加轮询或磁盘读写。
- 通过 Desktop 路由提示和远端状态索引变化发现 SSH 活动，覆盖 Desktop 未宣布新一轮的情况；任务状态仍向运行接口确认。
- 本机 Desktop 事件订阅改为原生采集，跳过对话正文，限制历史数据保留，降低采集的 CPU 与内存开销。
- 7 天额度曲线每 5 分钟保留一个读数，每 30 分钟合并保存；切换账号、额度周期重置、睡眠及正常退出时仍立即保存。异常退出可能丢失最后 30 分钟的本地曲线。任务、token 更新和额度读取频率保持现状。
- 任务仍运行时也持续提示待回复／审批，同时识别服务端请求和 Desktop 消息中的异步问题，覆盖本机及已启用的 SSH 来源。打开会话不会清除待回复提示；仅在 Desktop 中关闭问题浮层时，提示可能保留至观测到回复、问题移除或本轮结束。
- 刘海与悬浮模式采用已选定的原生状态图标和完整任务／待回复／待审批文字。单个运行任务显示当前阶段，多个任务显示数量。待处理提示直接放在对应任务行，额度告警保留在右侧；明确的失败事件与普通中断采用不同提示。
- Desktop 的任务发现信息会立即通知 SSH 运行接口建立订阅，任务状态以运行接口为准，避免桌面旧缓存覆盖真实状态；修复收尾更新误删完成提醒及下一轮延迟的问题。
- SSH 新一轮的首个工具事件补齐轮次 ID 时保留已确认的开始状态，防止旧完成记录覆盖正在运行的任务及新的完成提醒。
- 同一本地对话开始下一轮时保留事件监听；异步回复的 steering 消息也会清除待回复提示。按顺序交付事件，并在连接结束前刷新最后一批状态。
- 改进重连与结束状态、会话打开失败后的提醒保留、受限回退传输、CLI／应用发现及已保存的额度窗口选择。保留现有通知偏好。

本地测试沿用 ad hoc 签名，不代表已公证或公开发布。
