# Codex Pacer 2.0 中文宣传

受众是使用 Codex 的 macOS 用户。核心信息为“任务、速度、额度，抬眼即见”。所有界面来自 2.0 原生应用的演示模式，任务名、额度与输出速度均为样本，截图保留“演示”标签；没有真实账户或私人任务内容。

## 成品

`python3 marketing/render.py` 输出到 `output/marketing/2.0`：

- 中文主海报：1600 × 2400 PNG。
- 中文横幅：1920 × 1080 PNG，同时生成 README 用的 1440 × 810 图。
- 横版宣传视频：1920 × 1080、30 fps、42 秒，H.264/AAC MP4。
- 竖版宣传视频：1080 × 1920、30 fps、42 秒，H.264/AAC MP4。
- 中文字幕、关键帧预览、原创合成配乐和带 SHA-256 的素材清单。

视频依次展示灵动岛、订阅事件对应的思考/工具/回复/结束状态、点击任务的会话跳转演示、重置卡到期日期、七天趋势与重置券到期标注、折叠完成提醒和下载入口。宣传数字为界面样本，不代表性能测评或额度承诺。

## 修改与重新导出

安装 Python 3、Pillow、NumPy 及 ffmpeg（或 `imageio-ffmpeg`），在 macOS 上运行。脚本使用系统 PingFang SC 字体，不分发字体文件。海报与横幅的共用版式在 `business_campaign.py` 中，视频时间轴在 `render.py` 中；`--stills-only` 只生成静态稿供检查。

`source/island-*.png` 为真实演示界面截屏，`source/macbook-*.png` 为生成的设备素材。更新截图时先 `make build`，把构建路径传给 `bash marketing/make-demo-app.sh APP_PATH`，退出现有 Pacer 后在 Finder 打开打印的临时演示副本。该副本通过 `--demo` 启动，不查询 Codex。通过 Command+1/2/3/4 切换演示状态，截取思考、工具、回复与结束画面。点击任务可打开明确标注的演示会话窗口，正式模式仍跳转至 Codex。分别截图展开、收起、点击重置卡的到期标记后的状态，保留完整界面与演示标签。

演示趋势只含七天窗口，由不均匀工作时段和连续空闲平台组成。状态通过 `RuntimeEventState` 解析合成事件，不连接真实账户。宣传素材不将演示连接或跳转称为真实私人会话录屏。

MacBook 硬件场景由内置 Imagegen 生成，参考 Apple 官方 MacBook Pro 快速入门图示；macOS 风格桌面、菜单栏与硬件刘海遮罩按测量坐标合成。放大视图保留真实原生界面，模拟显示器几何用 `--demo-notch` 开启，不改变正式模式的显示器检测。没有使用生成式工具重画 UI、标志、数字或文字。产品标志来自 `native/Resources/Pacer.png`；配乐由脚本合成，没有外部音乐/配音素材。导出后检查画面、文字安全区、MP4 时长/分辨率/音轨与 `manifest.json`，宣传图单独交付并用于 README；Release 只提供 DMG 安装包。

## 已确认的海报设计

横版与竖版共用浅灰、石墨与青绿色版式：MacBook 中的灵动岛保持实测的 440 / 1728（约 25.46%）屏幕宽度；右侧独立特写用细引线连接，保留真实液态玻璃与重置券日期。宣传画面不包含下载链接、下载按钮或“刘海区域放大 / 演示数据”说明文字。

`desktop-liquid-glass.png` 来自 macOS 原生液态玻璃在拍摄背景上的完整屏幕截图，显示器色彩配置已转换为 sRGB；仅保留演示面板及其阴影，外围使用对应的拍摄背景，避免私人桌面内容。实测尺寸和玻璃设置保存在同名 JSON。拍摄需在演示设置中选择“液态玻璃 → 清透”，通透度 100%；单独截取透明窗口会丢失背后的桌面，不能替代完整屏幕采集。硬件图的提示词保存在 `source/macbook-studio-prompt.txt`。
